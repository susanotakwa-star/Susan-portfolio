# Sales Performance Dashboard  
## Project overview 
This project analyses sale data to understand business performance and identify trends.
## Objectives
- Analyse total sales and revenue
-  Identify top-performing products
-  Compare sales across different regions
-   Identify sales trends over time
## Tools used
- Microsoft Excel
-  Power BI
-  SQL
  ## Key insights
  This project will create insights that can help improve sales performance and support better business decision-making
